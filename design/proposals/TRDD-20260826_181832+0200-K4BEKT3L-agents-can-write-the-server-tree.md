## Problem

Every agent runs as the same uid as the ai-maestro server, and the server's own code is
writable by that uid. An agent can patch the guarantor it is supposed to be constrained by.

## Evidence (measured 2026-08-26, this host)

```
~/ai-maestro/server.mjs      writable=True
~/ai-maestro/lib             writable=True
~/ai-maestro/node_modules    writable=True
~/ai-maestro/.next           writable=True
```

## Why this outranks every other impersonation vector

It defeats all three proposed layers at once:
- the kernel-peer-credential identity check (A) is code an agent can edit;
- the per-agent sandbox profile is generated by code an agent can edit;
- the encryption-at-rest design is WORSE under this vector, not better — the server is the
  one process authorised to unlock the keychain, so patching it is how you ask the keychain
  nicely.

A design in which the guarantor's own code is writable by the parties it guards is
decorative, whatever else is layered on top.

## Task

1. INVESTIGATE — enumerate every path the server loads code from at runtime
   (`server.mjs`, `lib/*.mjs` runtime-imported, the `.next` bundle, `node_modules`,
   any plugin/script layer the server execs).
2. ASSESS — confirm the write is reachable from an agent's actual shell, not just
   from this session's uid.
3. SAFEGUARD — root-own or otherwise make immutable the server tree, so the uid the
   agents run as cannot write it. Decide the operational shape (root-owned install vs
   `chflags schg` vs a separate service account for the server) and its upgrade path,
   because `bump-version.sh` / `yarn build` must still work.

## Acceptance

- [ ] Every runtime-loaded server path enumerated, with its current owner and mode recorded.
- [ ] A probe run AS AN AGENT (not as this session) proving the write is or is not reachable.
- [ ] A safeguard applied that makes the enumerated paths unwritable by the agent uid.
- [ ] The publish/build path still works after the safeguard, demonstrated.
- [ ] A regression check that fails if any enumerated path becomes agent-writable again.

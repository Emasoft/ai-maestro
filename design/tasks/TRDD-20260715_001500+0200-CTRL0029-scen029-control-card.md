# SCEN-029 control card

## Problem

This card is the CONTROL for SCEN-029's negative test. It is approved through the
real route (`POST /api/trdd/[id]/approve`), which MINTS a host-signed,
ledger-anchored approval token pinned to this card id.

Its only job is to prove that `verify` CAN return VERIFIED. A verifier that
refused every card would also "pass" the forgery test in S017, and would prove
nothing. This card is the counterexample that makes the forgery test meaningful.

## Verification

`GET /api/trdd/CTRL0029/verify` must return `verified: true` with a `token_id`.
